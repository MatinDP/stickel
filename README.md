# Stickel

ویرایشگر ویندوزی ساخت استیکر از تصویر و ویدیو، با رابط فارسی/انگلیسی و تم روشن/تیره.

## دریافت نسخه ۱.۱.۰

- [دانلود نصاب ویندوز x64](https://github.com/MatinDP/stickel/releases/download/v1.1.0/Stickel-Setup-1.1.0-x64.exe)
- [دانلود نسخه قابل‌حمل ZIP](https://github.com/MatinDP/stickel/releases/download/v1.1.0/Stickel-1.1.0-win-x64.zip)
- [یادداشت‌ها و هش فایل‌ها](https://github.com/MatinDP/stickel/releases/tag/v1.1.0)

## اجرا

- نسخه قابل‌حمل: ZIP را کامل استخراج و `Stickel.exe` را اجرا کنید. پوشه `runtime` و DLLها باید کنار برنامه بمانند.
- نصاب: `Stickel-Setup-1.1.0-x64.exe` برای حساب فعلی ویندوز نصب می‌کند. اتصال پسوند `.stickel` و میانبر دسکتاپ اختیاری‌اند.
- برنامه به نصب .NET یا codec pack نیاز ندارد. پردازش رسانه محلی است.
- هدف: Windows 10/11 شصت‌وچهاربیتی و دستگاه دارای Direct3D 11. نسخه ویندوز فعلی میزبان بررسی شده؛ همه سخت‌افزارها و نسخه‌های ویندوز آزمایش نشده‌اند.

## گردش کار

۱. فایل‌ها را وارد کنید؛ تصاویر ثابت و رسانه‌های متحرک در دو گروه جدا قرار می‌گیرند. ورود با انتخاب فایل، رهاکردن فایل یا `Ctrl+I` انجام می‌شود.
۲. دوبار کلیک یا «افزودن به تایم‌لاین» رسانه را اضافه می‌کند. تصاویر ثابت پیش‌فرض یک ثانیه‌اند.
۳. انتخاب بخش، کراپ، Fit/Fill، زوم، جابه‌جایی و تریم همان بخش را فعال می‌کند. دستگیره‌های اطراف تصویر برای تغییر اندازه و چرخش رسانه‌اند؛ Shift چرخش را در گام‌های ۱۵ درجه تنظیم می‌کند. دستگیره‌های دو سر بخش تایم‌لاین برای تریم و کشیدن وسط آن برای تغییر ترتیب‌اند.
۴. واترمارک برای تمام بخش‌ها مشترک است. شفافیت ۰٪ یعنی کاملاً پیدا و ۱۰۰٪ یعنی نامرئی. اندازه برحسب درصد عرض بوم خروجی است.
۵. پیش‌نمایش «بخش انتخاب‌شده» یا «کل تایم‌لاین» را انتخاب کنید. ویدیوهای معمولی بدون چرخش مستقیماً پخش می‌شوند؛ پیش‌نمایش کل تایم‌لاین و رسانه‌های چرخیده ابتدا رندر موقت می‌شوند. آماده‌سازی قابل لغو است. جلو و عقب‌بردن با دکمه‌ها و نوار زمان هنگام پخش، پخش را ادامه می‌دهد. ولوم و بی‌صدا کردن پلیر مستقل از گزینهٔ «خروجی بی‌صدا» هستند.
۶. در حالت تلگرام، WEBM/VP9 بدون صدا و با کیفیت خودکار زیر ۲۵۶ KB ساخته می‌شود. زمان بیشتر از ۳ ثانیه متوقف و خطا نمایش داده می‌شود. GIF/MP4 از حالت «خروجی آزاد» قابل تولیدند.
۷. خروجی کامل همیشه ساخته می‌شود؛ چک‌باکس خروجی جداگانه، فایل‌های هر بخش را هم در `parts` می‌سازد. هیچ فایل ورودی بازنویسی نمی‌شود.
۸. برای PNG/WEBP ثابت، فایل کل تایم‌لاین از فریم زیر نشانگر پخش و فایل هر بخش از اولین فریم پس از تریم ساخته می‌شود. خروجی شامل کراپ، موقعیت و واترمارک است.
۹. `.stickel` یک بسته ZIP نسخه‌دار با فشرده‌سازی است که تنظیمات و تمام رسانه‌های اصلی را نگه می‌دارد. ویدیوهای ازقبل‌فشرده‌شده ممکن است کاهش حجم اندکی داشته باشند.

## میانبرها

| عمل | میانبر |
|---|---|
| واگرد / ازنو | Ctrl+Z / Ctrl+Shift+Z |
| ذخیره / ذخیره با نام | Ctrl+S / Ctrl+Shift+S |
| بازکردن / پروژه جدید | Ctrl+O / Ctrl+N |
| واردکردن رسانه | Ctrl+I |
| پخش یا مکث | Space، بیرون از فیلد متن |
| فریم قبلی یا بعدی | کلیدهای چپ/راست، بیرون از فیلد متن |
| حذف بخش انتخاب‌شده | Delete، بیرون از فیلد متن |
| لغو عملیات جاری | Escape یا دکمه لغو |

## ساخت از سورس

در PowerShell و ریشه پروژه:

```powershell
.\tools\build.ps1 -Test -Package -Installer
```

اسکریپت ابزارهای pin‌شده را در `.tools` و موتورهای رسانه را در `runtime` قرار می‌دهد. SDK سراسری نصب نمی‌کند. ابزارها از Microsoft، GitHub، NuGet و Gyan دریافت می‌شوند و بسته‌های رسانه/نصاب با SHA-256 بررسی می‌شوند.

اجزای اصلی: `Stickel.Core` برای مدل، ورودی، بسته پروژه و خروجی؛ `Stickel.Desktop` برای WPF/MVVM و Flyleaf؛ دو پروژه آزمون برای رسانه واقعی و رفتار ViewModel.

## محدودیت‌های روشن

- پوشش فرمت‌ها به decoderهای همراه برنامه وابسته است؛ فایل خراب، DRM و کدک‌های ناشناخته با خطا گزارش می‌شوند.
- MP4/H.264 شفافیت ندارد و از رنگ پس‌زمینه انتخابی استفاده می‌کند؛ ابعاد MP4 باید زوج باشند.
- برآورد حجم خارج از حالت محدود تلگرام تقریبی است. مقدار واقعی پس از encode مشخص می‌شود.
- مدیریت پک، انتشار مستقیم در تلگرام، حذف خودکار پس‌زمینه و متن‌گذاری در دامنه تأییدشده این نسخه نبودند.
- برنامه و نصاب امضای دیجیتال ندارند.
