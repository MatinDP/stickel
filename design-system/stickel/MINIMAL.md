# Stickel minimal theme

User direction: a simple, polished dark/light interface with a black or white background. The verified UI/UX Pro Max minimalism style matches the monochrome palette and restrained decoration.

- Solid black window background in dark mode; solid white in light mode.
- Opaque neutral panels, gray borders, compact rounded controls and Font Awesome icons.
- No gradients, blur, transparency, reflections, shadows or decorative background layer.
- Primary action uses the inverse foreground/background palette. Selection, hover and keyboard focus use neutral tones.
- Keep the existing settings / preview / media positions, timeline features and theme/language switch.
- All resources live in `Themes/Minimal.xaml`; palettes live in `ThemePalette.cs`.
- `--theme` checks exercise native control behavior, text readability and both palettes/languages, with independent renders under `artifacts/theme-minimal`.
